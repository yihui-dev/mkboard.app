## MkBoard 是什么

MkBoard 是一个以分镜为基础的 AI Agent 工作台，面向视频创作者、课程作者、广告团队和动画创作者。你可以把脚本、口播稿或剧情需求交给它，由 Agent 拆成可编辑的镜头结构，区分 A-roll 与 B-roll，并为每个镜头规划画面、素材和生成方式。

它的核心不只是写脚本，而是把 B-roll 的生产流程接到分镜里：通过 Claude、Codex 等 Agent 理解项目上下文，再结合 ChatGPT Image、Seedance 等图像和视频生成模型，为镜头生成可用的图片或视频素材。参考图、角色、场景、生成结果和视频草稿都会回到同一个项目里管理，让创作者能持续修改和复用，而不是每次从零开始。

## 核心工作流

1. 输入脚本、剧情需求、课程讲稿或广告卖点。
2. 让本地 Agent 拆成镜头、画面描述、台词、素材需求和执行备注。
3. 在分镜表里继续调整镜头顺序、画面和节奏。
4. 绑定参考图、角色图、场景图和生成结果。
5. 通过 HyperFrames 生成可预览的视频草稿，再继续迭代。

## 适合谁

- 短视频创作者：把口播、剧情或热点想法快速拆成可拍摄分镜。
- 课程作者：把长讲稿拆成 A-roll、B-roll 和辅助画面。
- 广告与产品团队：围绕卖点、镜头和素材版本持续迭代。
- 动画与 AI 视频创作者：在生成之前先稳定角色、场景、镜头和节奏。
